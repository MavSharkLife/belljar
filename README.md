# The Bell Jar — direct-link archive

A static set of 13 standalone pages. There is no directory or navigation; open each page by its filename, from `01.html` through `13.html`.

## Hosting

This is plain HTML, CSS, and local image assets. It has no build step. For Cloudflare Pages, use the `main` branch, leave the build command blank, and set the build output directory to `.` (the repository root).

See [SOURCES.md](SOURCES.md) for image credits, article references, and reuse notes.
